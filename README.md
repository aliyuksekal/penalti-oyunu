# Penaltı Ustası: Kaleci Seni Okuyor

Godot 4.7 ile Android için yerel 3D penaltı oyunu. Kaleci ve şutçu yapay zekâ, oyuncunun
alışkanlıklarını cihazda öğrenir.

- Karakter animasyonları: `v1` sürümündeki Mixamo paketi (soccer_pack.zip) derleme sırasında
  Blender ile `.glb`'ye çevrilir (`tools/mixamo_to_glb.py`). Ham Mixamo dosyaları depoya konmaz.
- Derleme: `.github/workflows/android.yml` (imzalı AAB + APK, testler, ekran görüntüleri).
- Belgeler: `docs/`.
